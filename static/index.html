Secure Digital Evidence Transfer

Hand over evidence without handing over the keys.

Files are encrypted in your browser before they are uploaded. The server stores only ciphertext and cannot read it.

Encrypted before upload
AES-256 with an integrity check. The file key is wrapped for one named recipient.
Signed by the sender
Every transfer carries a signature that the receiver verifies before opening it.
Logged end to end
Each action is added to a tamper-evident audit log that an administrator can verify.
Private keys stay in this browser tab. Only public keys are sent to the server.
